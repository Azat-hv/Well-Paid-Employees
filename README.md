# Well-Paid-Employees
This project provides a SQL Server solution for a common HR analytics and FAANG interview problem: identifying employees who earn a higher salary than their direct managers. The repository includes a custom 50-row sample dataset that simulates a realistic corporate hierarchy consisting of executives, middle managers, and regular employees. To solve the problem, the project utilizes a SQL Self-Join approach, matching the employee table to itself via the manager ID. This allows for a direct row-by-row comparison of employee and manager salaries. The provided script sets up the database schema, inserts the mock data, and demonstrates the exact query needed to filter and extract the target employee records.

This query algorithm was written entirely by my own effort, without any assistance from artificial intelligence.
